# Yantratmika Solutions

Company website showcasing Yantratmika Solutions - a technology company specializing in Generative AI, IoT, and Full Stack Development.

## About

Yantratmika Solutions provides digital transformation services for organizations ranging from startups to enterprises. We specialize in:

- **Generative AI**: Custom AI agents for business automation and intelligent decision-making
- **Industrial IoT**: End-to-end IoT solutions for device connectivity and cloud integration
- **Full Stack Development**: Web and mobile applications, project management tools, and CRM systems

## Website Pages

- `index.html` - Homepage with service overview
- `ai.html` - Generative AI solutions and capabilities
- `iot.html` - IoT solutions and platform features
- `team.html` - Leadership team and company values
- `projects.html` - Featured products and services
- `get-started.html` - Contact form and project inquiry
- `styles.css` - Unified styling for all pages

## Technology Stack

Built with:
- HTML5
- CSS3 (Responsive design with Grid and Flexbox)
- Vanilla JavaScript (minimal usage)
- Modern web standards
